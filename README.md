# BeerTracker – Mobile Beer Rating App

Dieses Projekt wird aktuell im Rahmen des Moduls **Entwicklung mobiler Applikationen** als Teamarbeit entwickelt und befindet sich noch **in progress**. Ziel der App ist es, eine persönliche Sammlung von Bieren aufzubauen, die man bereits probiert hat, und diese anhand von Geschmack und Bewertung zu dokumentieren.

## 🍺 Zweck der App

BeerTracker ermöglicht es Nutzer:innen, eine eigene Datenbank von probierten Bieren aufzubauen. Zu jedem Bier können Informationen wie Geschmack, Besonderheiten und ein persönliches Rating gespeichert werden, um langfristig den Überblick über Lieblingsbiere und Geschmacksvorlieben zu behalten.

## ⭐ Features 

- Anlegen und Bearbeiten von Bieren  
- Individuelle Bewertung (Rating) für jedes Bier  
- Geschmacksprofil/Tasting Notes hinzufügen  
- Übersicht aller gespeicherten Biere  
- Import und Export der persönlichen Bierdatenbank im **JSON-Format**  
- Vollständig offline nutzbar – kein Backend notwendig  

## 🛠️ Technologie

Die App wurde im Rahmen des Projekts vollständig **ohne eigenes Backend oder externe API** umgesetzt, um den Projektumfang einzuhalten.  
Die Daten werden lokal auf dem Gerät gespeichert und können bei Bedarf als JSON-Datei exportiert oder wieder importiert werden.

## 👥 Teamarbeit

Die Entwicklung erfolgte in einer kleinen Projektgruppe im Modul *Entwicklung mobiler Applikationen*. Aufgaben wie UI-Design, Datenmodellierung und Implementierung wurden gemeinschaftlich bearbeitet.

## 📦 Projektumfang

- Mobile App zur lokalen Datenspeicherung  
- Fokus auf userfreundliche Eingabeformulare  
- Einfache, intuitive Darstellung der persönlichen Bierhistorie
